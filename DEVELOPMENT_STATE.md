## Key decisions (cumulative)
1. Unity 6.3 LTS + Fusion 2.1.3.
2. Rules in pure C# (`WarOfNyx.Core`), shared by server, prediction, offline simulation and bots.
3. Online isolated behind `WON_FUSION` and `IOnlineSessionService`.
4. Dedicated servers for public matches. Host mode only for private test rooms (invisible, code-only, host START).
5. Networked movement: intent-only inputs sanitized on the server; full movement state is networked and restored each tick.
6. **Phase 4:** sessions start in a MatchLobby scene; the server-side `MatchLifecycle` decides when to load, spawn and unlock. Quick Match = Fusion random join filtered by protocol version and mode. Late joins refused by closing the session and refusing connect requests. Synchronized start = shared simulation-time threshold evaluated per tick. Spawns = seeded farthest-point sampling over validated candidates with safe relaxation. Spawn protection runs 3 s from FIGHT and is broken by any aggressive action.
7. Public default needs 12 players. Two-player dev mode is explicit (`-minPlayers 2`).
8. Starting inventory moved to Phase 6 (with the inventory system). Health 100 / armor 0 initialized now.
