## Key decisions
1. Unity **6.3 LTS** (6.0 LTS standard support ends Oct 2026).
2. Rules in a **pure C# assembly**, shared by the online server and the offline simulation (spec 38.14). Movement follows the same pattern: `MovementModel` is pure, and `PlayerMovement` only does collision.
3. **Fusion Server mode** for public matches. Host mode only for private test rooms.
4. Input actions **built in code**. Touch joystick/buttons are Input System On-Screen controls (virtual gamepad). Swipe-look and sprint toggle feed the router directly.
5. Character faces the **aim yaw** (strafe-style shooter movement). Sprint needs mostly forward input and no aiming. Crouch is a toggle. Crouch-while-sprinting = slide. A slide ends standing if there is headroom.
6. `MovementCommand` is the shared intent format for humans **and** bots.
7. Offline phase scheduled as **9G**.
8. Namespaces avoid `Android` / `Input` / `Editor`.
