## Key decisions
1. Unity 6.3 LTS. **Fusion 2.1.3** (stable since Jun 2026, supports 6.3), not 2.0.x.
2. Rules in pure C# (`WarOfNyx.Core`), shared by server, client prediction, offline simulation and bots.
3. Online is isolated in `WarOfNyx.Networking` behind `WON_FUSION`. The game talks to it only through `IOnlineSessionService`, so it builds without Fusion.
4. Fusion **Server mode** for public matches, **Host mode only for private test rooms**, Client to join. Session join by name through Photon Cloud.
5. Networked movement: input = intent only (stick, aim, 5 button bits), sanitized on the server. The full `MovementState` plus grounded flag plus position is a networked struct restored at the start of every tick. Prediction and reconciliation come from Fusion re-running `FixedUpdateNetwork`.
6. Edge buttons (jump/crouch/slide) are sent as per-tick bits. Fusion's per-tick inputs make them exactly-once.
7. Temporary ring spawns. The real spawn system is Phase 4.
8. Namespaces avoid `Android` / `Input` / `Editor`. Fusion's `GameMode` is aliased against the game's `GameMode`.
